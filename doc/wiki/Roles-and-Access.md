# Roles and access

The standard defines three roles (see the [guide index](https://github.com/The-Shadow-on-the-Moon/governance/blob/main/guides/README.md)). A role is a set of duties, and one person may hold several.

| Role | Held by | Repository access |
|---|---|---|
| Administrator | Damian Bucovsky | Admin |
| Project owner | Damian Bucovsky | Admin |
| Developer | Damian Bucovsky, Pablo | Admin (Damian), Write (Pablo) |

Every other member of the organization (for example Claudia) can read the repository, through the organization's default repository permission, not through a grant on this repository. Reading is not a role, and it gives no part in the process.

The same information is kept in [`AGENTS.md`](https://github.com/The-Shadow-on-the-Moon/governance/blob/main/AGENTS.md) so that assistants and people read the same thing. Change both together.
